🌸 Cosmira Skincare

About the Project

Cosmira Skincare is a skincare website designed to explore skincare products and beauty essentials. 
It provides a simple and user-friendly interface for discovering skincare products.

Features
- Attractive and responsive user interface
- Explore skincare products
- Product details
- Easy navigation
- User-friendly design

Technologies Used
- HTML5
- CSS3
- JavaScript
